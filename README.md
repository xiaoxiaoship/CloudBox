# CloudBox

CloudBox 是一个运行在本机的多用户网盘：文件保存在自己的电脑或服务器上，局域网和公网用户通过浏览器访问。它适合家庭、工作室和小团队管理文件、分享链接与静态网站。

## 主要功能

- 多用户账号、空间配额、登录失败锁定与改名限制
- 文件上传、下载、移动、复制、重命名、删除、在线解压
- 图片、视频、音频、PDF、Word、Excel、PPT、TXT 在线预览
- 文件分享直链与有效期控制
- 静态网站托管：把网盘文件夹直接发布为网站
- frp 内网穿透与定时在线模式
- 管理员 Web 控制台、插件系统和自定义预览扩展
- 可选 AI 文件助手、邮件告警、ClamAV / VirusTotal 查杀
- 基于 GitHub Releases 的更新提示，不静默替换程序

## 快速开始

1. 运行 `CloudBox-Setup-1.0.0-x64.exe` 安装，或直接运行便携版。
2. 首次启动创建管理员账号。
3. 在网络设置中开启 Web 服务。
4. 用管理员提供的账号登录 Web 端上传文件。
5. 需要公网访问时，在同一个网络设置页配置 frp。

## 数据与隐私

- 文件与数据库默认保存在本机，不上传到第三方云盘。
- AI 和邮件功能仅在管理员主动配置后启用。
- 插件运行在独立进程中，启用第三方插件前请确认来源可信。
- 静态托管页面与主站隔离，不能调用主站 API。

## 更新

程序只检查 GitHub Releases 并提示下载，不会自动覆盖安装。安装版可直接覆盖升级，便携版替换程序文件即可，账号和网盘数据保留。
